# 求职与具身模块 · 0.3.9 实现说明

本轮重点是持续发现、增量更新和有证据的匹配。macOS 构建已通过 501 项原生检查、15 个 XCUITest 场景和模拟器／iPhone 编译，未签名 IPA 已发布。真实本人画像导入、账号、接口和设备权限仍需 iPhone 验收。源代码实现不等于已经取得所有网站的账户与接口权限。23 条公开来源研究资料只用于离线启动和回归检查，不是持续采集的替代品。

## 采集与持续更新

电脑运行独立 Node 服务，App 通过 GET /v1/career/feed 读取、POST /v1/career/refresh 请求刷新。浏览器预览通过同源代理访问服务，服务令牌不进入网页脚本。

服务默认每 3 天执行一轮，保留手动刷新，保存调度、来源退避、查询进度和请求预算。方向关键词、杭州关注公司和其他城市分别轮换，不让小批首页结果替代全站覆盖。每轮按预算读取列表，再优先补全岗位详情；验证码、未登录、未配置与真正无结果分开记录。电脑关闭期间 App 仍能读取本机缓存，联网重新连接才接收新结果。尚未部署常驻云端服务。

BOSS 使用本人在电脑采集器首次登录后留下的独立会话，后续调度复用；手机已经登录不会自动授权电脑。遇到验证停止并保留旧岗位，需要本人处理。实习僧官方搜索和详情接口需要商务凭据与 IP 白名单；另外支持公开详情页面。来源自身字段变化可能需要维护适配器。公司官网、高校、牛客、智联公开详情以及搜索服务各有独立状态，不把目录数量当作采集覆盖数量。

来源页展示实际尝试时间、成功时间、查询词、公司、列表／详情数量、下次尝试及每日预算。完整性看实际扫过哪些范围以及仍有哪些缺口，不靠增加静态样例数量评判。

## 岗位身份与数据质量

先用来源岗位 ID／规范网址辨认同一岗位，再尝试跨来源合并。不同团队、不同来源的相似职位，在职责和条件证据不足时保留独立条目。合并保留原始来源链接，收藏通过岗位身份和网址别名延续。

新列表摘要不能擦除旧完整 JD 的毕业届次、出勤天数、实习月份等条件。有限分页中没有看到旧岗位，不作为已关闭的证据；明确下线和截止日期才关闭。发布日期、来源刷新日、成功核查日分别保存，不把搜索时间改成发布时间。刷新失败保留已有内容，长时间未核查的条目降低招聘状态确定性。

## 匹配与推荐

列表显示来源 JD 摘要，详情先展示岗位职责与任职要求，再展示公司和来源。删除“为什么与你相关”；匹配仅用于筛选和排序，补充条件与模型分析默认折叠。缺失 JD 明确提示，不用模型填造。

先检查明确的实习身份、用户在本机画像填写的毕业年份、截止日期和用户选定的出勤／时长。明确不符不进入当前推荐；未知条件保留并标明需核对。城市优先级和分组范围由本机画像设置，各组可展开全部结果，不只显示一个岗位。

职责相关性按岗位技术方向分别评估。岗位公司简介、招聘方的匹配说明及能力缺口，不作为招聘职责证据；能力状态从本机画像读取，计划学习或待确认的项目不会按已掌握处理。Python、仿真、C++ 的已确认实践给予小幅排序加分；岗位明确要求 VLA 或强化学习时，只有画像中已确认且写有对应实践事实，规则排序才取消该项缺口扣分。

可选模型分析默认关闭，开启后由用户点击“分析新增岗位”。模型分析会把本机画像中与岗位词项相关的最多 6 项能力事实、当前偏好和完整 JD 的有限摘录发送到配置的模型服务；没有词项命中时仅选前 2 项已确认事实。Key 保存在手机钥匙串，不传给岗位采集服务。只有完整详情参与模型分析，列表线索不消耗模型 Token。引用必须出现在发送的岗位摘录里；模型不能改变公司、薪资、地点、原始时间、招聘状态或硬条件。

分析按 JD 内容、画像版本及偏好缓存；没有变化不重复请求。单批最多 3 个，单岗位摘录最多 1200 字，输出最多 800 Token；每天按保守估计预留最多 6000 Token，失败计入预留且当天不重复自动请求，另记录接口实际 usage。模型分析属于辅助相关性判断，不是录用概率，也不是能力满足的保证。

## 数据与验证边界

App 岗位缓存、收藏、投递状态和模型缓存保存在 Application Support；求职画像保存在本机，并随完整备份导出。恢复备份时如果手机已有画像，保留手机现有版本；单独画像导入可先预览再保存。连接令牌和模型 Key 在钥匙串。电脑会话、来源凭据和岗位缓存在 data/career-private，源码和 IPA 不打包该目录。完整备份尚不包含求职岗位缓存与跟进状态；覆盖更新需沿用证书和 Bundle ID，卸载前应另存备份。

回归测试覆盖身份误合并、条件保存、过期筛除、失败保留、调度与预算、引用和能力限制，以及原生 UI 收藏重启。测试通过只能证明这些边界行为，不能把检查项数量当作真实岗位推荐准确率。本人 BOSS 登录链路、实习僧商务接口、真实模型匹配质量和 iPhone 局域网权限仍需要相应环境验收。

具身观察仍保留有原始日期的 LeRobot 历史资料；本轮没有声称已完成实时行业日报／周报采集。

服务配置和运行方式见 [采集服务](career-service.md)。借鉴开源项目常见的来源适配、列表到详情、持久会话、缓存与去重流程，未执行第三方爬虫或复制许可证未明确的实现。
