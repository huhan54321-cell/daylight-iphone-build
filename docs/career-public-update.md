# 公开岗位与具身观察 · 0.4.0

默认从公开 HTTPS 数据文件读取，不需要电脑脚本、局域网 IP、服务令牌或招聘网站登录。顶部刷新读取最近一次已发布的数据；不会立即触发全部来源重新采集。首次打开和内容超过一小时后返回页面会自动读取，失败时保留本地缓存。

公开更新任务每天运行一次，资讯每次更新，岗位距离上次成功尝试至少72小时才重新检索。GitHub 调度可能延迟；每个来源保留真实尝试时间和成功时间。搜索 Key 只保存在 GitHub 加密 Secrets，不进入公开源码、JSON 或 IPA。资讯规则与摘要摘录不调用大模型。

岗位检索覆盖杭州、其他城市、大公司与机器人企业官网、牛客、智联、高校公开招聘。关键词分别覆盖具身操作、仿真、模仿学习、VLA 和运动控制。BOSS 与实习僧不进入本版公开任务，旧缓存也从展示中排除。画像和硬条件筛选、排序仍在手机本地进行。

搜索摘要标为列表线索；只有读取到明确职责与要求段落才标记正文摘录。公司和城市不能从搜索查询词推断；未知保持未知。没有在有限查询中出现的旧岗位不会自动变成关闭。来源访问受限或未提供完整JD时保留链接与核查状态；不宣称覆盖所有岗位。

资讯涵盖行业动态、VLA与操作策略、模仿与强化学习、世界模型、仿真与评测、开源工具、灵巧手与产品落地。arXiv 从cs.RO相关查询获取论文题名、作者、摘要、首次提交及更新日期；Hugging Face通过RSS读取开源进展。新闻检索优先研究机构、公司和项目来源，产业报道可来自公开媒体。

日报仅展示北京时间当天的已知发布日期；周报展示今天及前六个自然日。没有原始日期的内容进入资料库，采集时间不能充当发布日期。论文更新版不会改写首次提交日期，预印本明确标识。技术关键词和摘要摘录用于阅读原文入口，不当作模型生成的专业判断。

公开任务不接收个人画像、简历、姓名、联系人、账本、健康或日历；公开数据只有第三方职位和资讯。画像、收藏、跟进、可选模型分析保存在手机。高级个人采集服务保留为可选项，默认关闭。
